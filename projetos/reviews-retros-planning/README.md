# Reviews, retrospectivas e plannings

Resumos de reuniões de **review de sprint, retrospectiva e planning** (transversais ou por squad) — diferente de [`../dailies/`](../dailies/), que é só standup. Sugestão de nome: `AAAA-MM-DD-tipo-squad.md`, ex.: `2026-08-28-retro-var.md`, `2026-08-31-planning-var.md`.

**Fluxo:** o mesmo de `../dailies/README.md` — toda vez que um resumo cair aqui, usar pra atualizar `../dashboard-executivo.html`, o `contexto.md` do(s) projeto(s) mencionado(s), `../README.md`, `../prioridades-sprint.md` e `../minhas-pendencias.md`.

Transcrições originais (.docx) não ficam aqui — só os resumos `.md`. **Nunca excluir documentos de projeto; só transcrições já digeridas podem ser removidas, e mesmo assim com cautela.**
