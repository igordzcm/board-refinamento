# Dailies — transcrições

Cole aqui as transcrições das dailies (um arquivo por sessão, sugestão de nome `AAAA-MM-DD-squad.md` ou `.txt`, ex.: `2026-08-12-retaguarda.md`).

**Fluxo:** toda vez que uma transcrição cair aqui, ela deve ser lida e usada pra:
1. Atualizar `../dashboard-executivo.html` (entregas, em andamento, bloqueios, riscos, próximos marcos).
2. Atualizar o `contexto.md` do(s) projeto(s) mencionado(s) em `../<projeto>/`.
3. Atualizar `../README.md` (índice) se o status ou prazo de algum projeto mudou.
4. Atualizar `../minhas-pendencias.md` com qualquer reunião a marcar, devolutiva do Igor pra alguém, ou coisa que alguém prometeu entregar pro Igor — e remover da lista o que já foi resolvido.

Transcrições já processadas podem ficar aqui como histórico — não precisa apagar.
